The ready-made shortcut isn't published yet.
You can build the same shortcut in Shortcuts in under a minute. It has two actions.

Build it yourself

  1. Open Shortcuts and tap + to make a new shortcut.
  2. Add the Take Screenshot action.
  3. Add the Ask Hermes About Screen action from Conduit. It picks up the screenshot from the step above.
  4. Name the shortcut Ask Hermes About Screen and tap Done.

Put it on a button

On iPhone 15 Pro and later, open Settings → Action Button, choose Shortcut, and pick Ask Hermes About Screen. On any iPhone you can also run it by saying “Ask Hermes About Screen” to Siri, from Back Tap (Settings → Accessibility → Touch → Back Tap), or from a Home Screen or Lock Screen shortcut widget.

Privacy

The shortcut only runs when you press it. The screenshot goes to your own Hermes gateway with the question you ask, the same way a photo you attach does. See the privacy policy.
