Help and contact

Hermes Conduit support

Get help connecting Conduit to your Hermes gateway, restoring a session, or configuring notifications.

Email support: support@milim.dev
For reproducible bugs and feature requests, you can also open a GitHub issue.

Before requesting support

  1. Confirm that your Hermes dashboard is reachable from Safari on the same iPhone.
  2. Open Settings → Gateway, refresh the connection, and use Sign in again if the dashboard session has expired.
  3. Include your iOS version, Conduit version, Hermes version, and the exact error message. Do not include API keys, session tokens, notification credentials, or private conversation content.

Connection problems

Conduit requires an HTTPS dashboard URL that the iPhone can reach. The dashboard completes authentication and grants the app a session token. If the connection cannot recover automatically, open the Gateway sheet from chat or visit Settings → Gateway to reconnect or sign in again.

Notifications

Notifications are optional. Enable them in Settings → Notifications, create a pairing code, and claim that code from the matching Hermes profile. Installation and pairing instructions are maintained in the notification plugin README.

Attachments

Conduit supports user-selected images, PDFs, and text files. If an attachment is visible in your message but the agent cannot read it, confirm that the Hermes gateway has write access to its configured image and attachment directories.

Privacy or deletion requests

Read the privacy policy. Questions and deletion requests can be sent to support@milim.dev.

Third-party status

Hermes Conduit is an independent client and is not affiliated with or endorsed by Nous Research. Support for Conduit itself is provided through the contact methods above.
